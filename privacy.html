TokenWatch 隐私政策

最后更新：2026年6月4日

1. 数据收集与使用

TokenWatch（以下简称“本扩展”）由开发者 Bing Dai（以下简称“我”、“我的”）提供。本扩展不会收集、存储或上传任何个人身份信息或对话内容。所有 Token 计算和预算跟踪均在您的本地设备上完成，使用 Chrome 浏览器的 chrome.storage.local API 进行存储。

2. 权限说明

本扩展仅请求实现功能所必需的最小权限：

  • storage：用于保存您的每日预算、消费记录以及专业版激活状态。所有数据仅存储在您的本地设备上，不会上传。
  • host_permissions：仅限于 chat.openai.com 和 chat.deepseek.com。仅在您主动使用扩展时（如右键设置预算或页面加载时）临时访问页面内容，用于估算 Token 消耗。不会在后台运行或访问其他网站。

3. 第三方服务

本扩展不向任何第三方传输数据。专业版（Pro）订阅支付通过 Creem 处理，Creem 的隐私政策请查阅其官方网站。

4. 数据保留与删除

所有数据保存在您的本地浏览器中。当您卸载本扩展时，Chrome 会自动清除这些数据。我无法远程访问或删除您的数据。

5. 儿童隐私

本扩展不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。

6. 隐私政策的变更

如果本隐私政策发生重大变更，我将在 Chrome 商店的产品描述或我的网站上发布更新。您继续使用本扩展即表示接受这些变更。

7. 联系方式

如果您对本隐私政策有任何疑问，请联系：support@1976.buzz（后续会升级为 support@tokenwatch.app）。
